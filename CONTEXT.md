# Compact XP Bottles

A Forge mod context for defining compact experience-bottle items and how they are used in gameplay.

## Language

**Tiered XP Bottle**:
A custom throwable bottle item that represents a fixed XP multiplier compared to the vanilla experience bottle.
_Avoid_: stack, level bottle, upgraded bottle

**Bottle Tier**:
The specific multiplier variant of a Tiered XP Bottle (for example x4, x16, x64, x1k).
_Avoid_: rank, grade, class

**XP Payload**:
The amount of experience a bottle releases when used.
_Avoid_: value, amount, points
